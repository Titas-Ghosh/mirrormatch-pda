The logic behind the mirror

Three phases. One decision.

A PDA uses a stack as unbounded last-in, first-out memory. Nondeterminism lets it guess the midpoint instead of needing to count the whole input first.

01 / PUSH

Remember

In q₀, push each symbol before the guessed midpoint. The stack stores the prefix in reverse-access order.

02 / GUESS

Split the string

Switch to q₁ at a guessed midpoint. For odd lengths, consume one center symbol without pushing or matching it.

03 / MATCH

Reflect

Compare each remaining input symbol with the stack top. Equal symbols pop; a mismatch kills that branch.

Formal definition

The language of palindromes

For a fixed alphabet Σ, a string belongs to the language if it equals its reverse. The empty string is also a palindrome. A correct nondeterministic PDA accepts if at least one branch reaches acceptance.

L = { w ∈ Σ* | w = wᴿ }
